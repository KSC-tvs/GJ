# Gulshan Jewellers | Est. 1950 — Digital Flagship

> **"Years of Crafting Legacies"**  
> An editorial luxury fine jewellery digital boutique specializing in 100% natural, certified gemstones, BIS hallmarked gold, natural diamonds, and handcrafted bespoke heirlooms.

---

## 💎 Features Overview

- **Multi-Currency Engine**: Live switching across INR (₹), USD ($), AED (د.إ), GBP (£), and EUR (€) with localized number formatting.
- **Curated Consultation Tray & Specification Matrix**: Shortlist up to 4 pieces with side-by-side gemstone comparison and 1-click WhatsApp tray export.
- **Global Command Search**: Quick search modal (`Cmd + K` / `Ctrl + K`) indexing both inventory and gemological guides.
- **Astrological Carat vs. Ratti Calculator**: Precision bidirectional calculator adhering to Vedic tradition (1 Ratti = 0.91 Carat).
- **International Ring Size Guide**: Comprehensive conversion matrix (Indian, US, UK, EU, mm) with step-by-step sizing instructions.
- **Mobile-First App Experience**:
  - Persistent Mobile Bottom Dock (Home, Catalogue, Search, Tray with live badge, Concierge).
  - Luxury slide-in navigation drawer with expandable categories and currency controls.
  - Slide-in faceted mobile filter sheet on the Collections archive.
- **Bespoke Creation Journey**: Interactive loose-stone-to-finished-signet transformation slider and bespoke commission form.
- **Sample Gemological Certificate Inspector**: Transparent specimen disclosure illustrating independent laboratory certification (refractive index, specific gravity, microscopic inclusion findings, thermal treatment disclosures).
- **Staff Catalogue CMS Portal**: Dedicated portal (`admin.html`) with real-time price overrides, availability toggling, tag management, and clean JSON export.

---

## 🛠️ Tech Stack & Architecture

- **Core**: Vanilla HTML5, Modern ES6+ JavaScript, Custom CSS Design System.
- **Styling**: Tailored CSS tokens (`tokens.css`, `base.css`, `components.css`, `pages.css`, `admin.css`).
- **Data Architecture**: Decoupled JSON data store with `localStorage` overrides for instant staff catalogue updates without server reboots.
- **Bundler / Server**: Vite Multi-Page Application (MPA) supporting 8 HTML entry points.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/KSC-tvs/GJ.git

# Navigate to project directory
cd GJ

# Install dependencies
npm install

# Start local development server
npm run dev
```

The site will be live at `http://localhost:3000/`.

### Production Build

```bash
# Compile and optimize for production
npm run build

# Preview production build locally
npm run preview
```
